The Spraydown logo: the mark (five shot dots in a downward chevron on a rounded square) and the wordmark in Chakra Petch Bold outlines, with "down" in volt. Files are vector; no font is needed.

| File | Use |
| --- | --- |
| `spraydown-logo.svg` | Logo on dark surfaces (`ground`, `inset`, `panel`): volt mark, `text` and volt wordmark. 307 × 64. |
| `spraydown-logo-light.svg` | Logo on light backgrounds: graphite mark and wordmark. 307 × 64. |
| `spraydown-wordmark.svg` | The wordmark alone, on dark surfaces. |
| `spraydown-mark.svg` | The mark and app icon: volt square, `volt-ink` dots. 64 × 64. |
| `spraydown-mark-graphite.svg` | The mark on light backgrounds: graphite square, volt dots. |
| `spraydown-mark-mono.svg` | The dots alone, one color. They are drawn in `currentColor`, so inline the SVG to set the ink; as an `<img>` it renders black. |
| `favicon-16.svg` | The 16 px drawing of the mark with larger dots, for sizes below 24 px. |

Keep clear space of at least half the mark's height around the logo. The mark is at least 16 px, the full logo at least 120 px wide. Do not stretch, rotate, outline or recolor single dots, and never set the wordmark in another font.
