# Post-Task Verification & Documentation Synchronization Rule

Whenever completing ANY coding, debugging, refactoring, or documentation task in this workspace, the AI assistant MUST strictly follow this completion protocol before reporting back to the user:

## 1. Run Automated Tests & Validations
- **Python**: If Python code, CLI tools, or tests were touched or affected:
  ```bash
  cd processing && python -m pytest tests
  ```
  Ensure all 19+ unit tests pass.
- **Specs Schema**: If `client/specs.json` or weapon parameters were modified:
  ```bash
  cd processing && python -m recoil_discovery.cli verify
  ```
  Ensure all weapons pass schema verification.
- **TypeScript**: If TypeScript/JavaScript files were modified:
  ```bash
  npm run tsc
  ```
  Ensure 0 type errors.

## 2. Synchronize Documentation & Plans
- **Roadmap**: Update `docs/roadmap.md` with task progress, check completed items `[x]`, and record any newly identified follow-up items.
- **Release Notes**: Update `docs/release-notes.md` with any user-facing changes, new features, or bug fixes.
- **Guides**: If CLI arguments, UI behaviors, or setup instructions changed, update `README.md`, `docs/capture.md`, or `processing/README.md`.

## 3. Git Hygiene & .gitignore Updates
- Inspect `git status`.
- If new temporary files, logs, scratch outputs, or media captures were generated by any scripts or tests, ensure they are excluded in `.gitignore` and `processing/.gitignore`.
- Remove any transient scratch files created during the task.

## 4. Preservation
- Never remove unrelated existing comments, docstrings, or license notices.
